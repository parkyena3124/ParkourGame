\# ParkourGame



Unity로 개발 중인 1인칭 파쿠르 게임입니다.



\## Phase 1 - 기본 움직임



\- WASD 이동

\- 마우스 시점 조작

\- 점프

\- 달리기 (Shift)

\- 웅크리기 (Ctrl)

\- 슬라이드 (Shift + Ctrl)



\## Engine



\- Unity 6.3 LTS

\- Universal Render Pipeline (URP)
