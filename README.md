# ParkourGame

Unity의 기능과 게임 개발 과정을 하나씩 배워가며 제작하는 1인칭 파쿠르 게임 프로젝트입니다.
Unity 버전은 6.3LTS 버전을 사용하고 있습니다.

아직 C# 프로그래밍 경험이 많지 않아 코드 작성은 전반적으로 AI의 도움을 받고 있습니다.
직접 코드를 처음부터 작성하기보다는 AI가 작성한 코드를 Unity에 적용하고 테스트하면서,
Character Controller, Raycast, Coroutine 등의 Unity/C# 기능이 게임에서 어떻게 사용되는지 알아가는 것을 목표로 하고 있습니다.

현재는 기본적인 플레이어 이동과 파쿠르 시스템을 구현하고 있습니다.
